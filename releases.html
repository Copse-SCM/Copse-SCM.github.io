Releases

Versions are dates: 2026.11.0 is the first release of November 2026, 2026.11.1 the next. Each release has builds for macOS (Apple Silicon and Intel) and Linux (x86_64), and a SHA256SUMS file to check them.

Nightly

Daily build of main

Built every morning (06:17 UTC) when main has changed, named like 2026.11.09-dev+abc1234: the date and the commit. It has everything new, and may have rough edges.

  • Downloads for today's nightly
brew install copse-scm/copse/copse-nightly

2026.11.0

Latest November 8, 2026

The first release.

  • Everyday version control: commit without a staging area, pick changes or single lines with commit -p, branch, merge, rebase, cherry-pick, revert, stash, tag.
  • Undo for everything: copse undo reverses the last commit, merge, rebase, reset or checkout.
  • Works with git servers: GitHub, GitLab and any git host over HTTPS or SSH, plus older cgit servers; shallow and partial clones; signed commits, submodules and Git LFS.
  • Merges like git's: renames and moved folders are followed, with -X options and octopus merges; 2,000 randomized stress rounds match git exactly.
  • A built-in terminal interface: run copse on its own.
  • Faster than git at status, commits and checkouts.
  • macOS, Apple Silicon3.7 MB
  • macOS, Intel4.1 MB
  • Linux, x86_644.3 MB
