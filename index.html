What's different

Faster than git

Three to four times faster status, two and a half to six times faster commits, and four times faster checkouts on a 50,000-file repository.

No staging area

commit takes everything, the paths you name, or the changes you pick one at a time with -p.

Undo for everything

copse undo reverses the last commit, merge, rebase, reset or checkout. Anything that would throw work away keeps a backup first.

Works with git

GitHub, GitLab, and any git server over HTTPS or SSH, with signed commits, tags, submodules and LFS. Merges give the same results as git.

Every step can be taken back

Copse keeps a record of every move your branch makes: each commit, merge, rebase and checkout. copse undo steps back through them, and running it again steps forward.

Run copse on its own for a screen with your changes, the commit graph, your branches, and that undo timeline. Pick single lines to commit, and pull or push without leaving it.

Install

Homebrew

macOS and Linux.

brew install copse-scm/copse/copse

For the daily build of main: copse-scm/copse/copse-nightly.

Download

For macOS (Apple Silicon or Intel) or Linux (x86_64), from the latest release.

tar xzf copse-*.tar.gz
sudo mv copse-*/copse /usr/local/bin/

From source

With Rust installed.

cargo install --git https://github.com/Copse-SCM/copse

More about installing: checking downloads, the nightly build, upgrading.

A quick tour

copse clone https://github.com/you/project.git
cd project
copse status                  # what changed, and where you stand against origin
copse commit -m "Fix login"   # no staging step
copse push
copse undo                    # changed your mind? undo the last move
