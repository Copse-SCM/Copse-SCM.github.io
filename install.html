Install Copse

Copse runs on macOS (Apple Silicon or Intel) and Linux (x86_64). Pick whichever way suits you; they all give you the same copse command.

Homebrew

The easiest way, on macOS or Linux. Upgrades come with brew upgrade.

brew install copse-scm/copse/copse

Download

A ready-made binary from the latest release. Unpack it and put copse on your PATH.

tar xzf copse-*.tar.gz
sudo mv copse-*/copse /usr/local/bin/

From source

With Rust installed. Builds in a minute or two.

cargo install --git https://github.com/Copse-SCM/copse

Downloads for 2026.11.0

  • macOS, Apple Silicon (M1 and later)3.7 MB
  • macOS, Intel4.1 MB

Other versions are on the releases page.

Check the download

Each release has a SHA256SUMS file. Put it next to the archive and run:

shasum -a 256 -c SHA256SUMS --ignore-missing

On a Mac, a file downloaded in a browser is quarantined, and Copse isn't signed with an Apple developer certificate yet, so macOS won't open it until you clear that: xattr -d com.apple.quarantine /usr/local/bin/copse. Homebrew and curl downloads aren't affected.

Check it works

copse version

Then try the guide, or run copse on its own for the interactive screen.

The nightly build

A build of the latest main is published each day it changes, named like 2026.11.09-dev+abc1234 (the date and the commit). It has everything new, and may have rough edges.

brew install copse-scm/copse/copse-nightly

copse and copse-nightly both provide the copse command, so install one or the other. The nightly is also on the nightly release page.
