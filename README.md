# copse-site

The website for [copse](https://github.com/Copse-SCM/copse): plain HTML and CSS, no build step. Open `index.html`, or serve the folder (`python3 -m http.server`).

Design: a light theme, a Times New Roman–style serif, and the logo's greens (#0C5C27, #3DBA6E). The commit graph appears only in its one illustrated section.
